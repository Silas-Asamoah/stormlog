# Issue #118: interim native integration decision

**Decision:** The native integration gate has not passed. Defer integrating a new native collector into Stormlog. Continue to treat existing semantic telemetry plus imported public or vendor traces as the interim path. This is a gate-based decision about integration now, not an empirical finding that this path has better memory use or attribution than direct CUPTI.

## Concrete experimental basis

- The frozen protocol is `final_run_proposal.json`, SHA-256 `2761ffde2dfff13c14d3d2f24ef4036c2a4e33c073b879e39a69b14e82933815`. It requires five complete matched repetitions per mode and workload, 200 warmup plus 2,200 measured requests at 0.1-second offsets, and the declared failure rules. Zero of the 20 planned final vLLM mode repetitions have run.
- One full profiler-off L4 preflight passed: 200/200 warmup, 2,200/2,200 measured, 2,029/2,029 valid RSS rows, 203/203 valid GPU-memory samples, and clean exit. Evidence: `evidence/preflight-off-full-shutdown-l4-525221-23.json`. This qualifies that preflight only.
- A full direct-CUPTI capacity preflight finalized 116,213,134 records in 3,325,819,298 encoded bytes, with STOP acknowledgment and zero reported drops. Evidence: `evidence/preflight-vllm-capacity-4g-stop300-l4-524654-08.json`. It establishes capture capacity in one run, not a memory advantage, request/phase attribution, or external completeness.
- The full stack-free public-engine preflight served 200/200 warmup and 2,200/2,200 measured requests and produced 2,103 valid resource rows. `/stop_profile` timed out after 300 seconds; EngineCore was force killed, a leaked semaphore was logged, and no rank-0 trace was exported. Evidence: `evidence/preflight-public-engine-stack-free-full-l4-525237-25.json`. The local raw archive SHA-256 is `62342d536ed484dfe7541f5be666d700b282cc07aa80679dd90043d6f1089acc`; all 17 internal hashes verify. This is a failed partial, not an eligible public memory baseline.
- A bounded 200-measured-request stack-free public run retained CPU operations, CUDA runtime/driver activities, GPU kernels, and host-device flows, but produced 198 resource rows against its exact 200-row diagnostic check. Earlier stack-enabled public runs missed stop acknowledgment. Proton and trusted Nsight vLLM smokes retained teardown errors. Simultaneous Nsight and direct CUPTI produced no direct kernels on this stack. These are limits, not proof that the approaches never work.

## What the evidence does and does not decide

The public full-workload stop/export/teardown gate failed, so the frozen paired memory comparison has no qualified public denominator. There is no paired memory effect or uncertainty interval, no total-memory result, and no measured collector winner. Pinned host memory and actual collector-buffer memory remain unmeasured. CUPTI activity has host/device correlation identifiers but no request or inference-phase semantics by itself; a supported join to Stormlog or engine annotations would have to be qualified separately. No production-readiness claim follows.

The source-backed eight-candidate, 24-field matrix is a screening worksheet, not a score. Its separate Stormlog-validated matrix retains 192 UNKNOWN cells. UNKNOWN means unqualified, not unsupported. The eight candidates are PyTorch/Kineto, vLLM Proton, direct CUPTI Activity, host USDT/uprobe/eBPF, a CUPTI/eBPF hybrid, Neutrino, ROCProfiler, and no new native collector. Host-only probes lack asynchronous device execution timing; the hybrid adds native and BPF privilege, packaging, and loss domains; Neutrino addresses lower-level device questions; ROCProfiler requires an independent AMD lane. No new collector minimizes new native ownership while retaining the limitations of imported traces.

**Revisit condition:** An exact, separately approved full-window comparator or capture method must preserve the attribution question, trace completeness and loss evidence, clean teardown, and the frozen workload and failure rules. It then needs qualified applicable full-workload and trusted correctness preflights before separately authorized matched repetitions. Do not repeat the failed public mode or extend its stop wait under the prior approval. Preserve all partials and keep #235, especially AMD, open.

**Local retention:** The exploratory code, schemas, tests, protocol amendments, and individual preflight records removed from the PR diff are retained locally in `artifacts/native-probes/readiness/pr239-local-retention-cf7476a.tar.gz` (SHA-256 `2924a10831964097bdbc2b9b24b56167913bb343e2eadc68f1430eb713cded59`). The local archive is not a remote durable backup.

**PR handling:** Keep PR #239 draft and focused on the decision, frozen protocol, matrices, and the preflights needed to substantiate the gate result. The prototype is not selected for integration. Do not close #118 or #235 on this interim decision.
